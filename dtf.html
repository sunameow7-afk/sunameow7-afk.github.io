Walkthrough

Every screen and button, explained.

From the activation screen to the Danger Zone: exactly what each part of DTF does before you ever click anything.

License Activation

The first screen. Paste your key and hit ACTIVATE: the key binds to your PC's HWID. COPY HWID puts your machine ID on the clipboard for tickets, GET KEY sends a key request from inside the app, JOIN DISCORD opens the server. One key, one PC.

First scan

Right after activation DTF runs a quick pass over your system, then hands you the OPEN DASHBOARD button into the main panel.

Main Panel

The home of the 20 system cleaners: temp files, prefetch, event logs, browser history, and more. Every tile is one target: click it and the button flips to “Cleaning…” with a live status line until it reports the honest result. Zero settings to configure.

Network & Browser

Network-side leftovers: DNS caches, saved browsing histories and connection traces. One click each, same live status as the main panel.

Memory Tools

Clears RAM, jump lists and in-memory activity trails normal cleaners never touch. The String Cleaner wipes chosen strings straight out of running processes, presets included for svchost, explorer and lsass.

Trace Scanner

Type any name (or BROWSE EXE to pick a program) and DTF finds every leftover file, registry entry and log it left on every drive, then cleans exactly what you select.

Advanced

Deep tools for power users: activity timeline, GUIDs, USB traces, ETL logs and other buried artifacts the one-click panels don't reach.

Danger Zone & self-destruct

The exit path. Closing DTF (X, Alt+F4 or self-destruct) wipes files, registry, prefetch, browser evidence and history, then deletes the exe itself. Rerun the install command next time; a final verification scan always shows the honest result.

FAQ

Questions, answered.

How do I run DTF?
Open a ticket in our Discord and copy the install command, paste it into PowerShell as Administrator and press Enter. The encrypted payload downloads and DTF opens. To reinstall later, just run the command again.
Does DTF leave anything on my PC?
No. Closing DTF triggers a full self-clean (files, registry, prefetch, browser evidence, PowerShell history), then deletes itself, and a final verification scan confirms zero leftovers on screen.
How much does it cost?
₱500 ($8) for 1 day or ₱5,000 ($80) for lifetime. See the Pricing section above. Open a ticket, pick your plan, pay via GCash or PayPal, and your key lands in the ticket.
Is my license locked to one PC?
Yes. Every key is bound to your hardware ID (HWID) on first activation. One key, one PC. Moving PCs? Open a ticket and we can reset it.
Will antivirus flag it?
DTF is a cleaner that deletes files and edits the registry, so some AVs flag tools like that by default. The launcher adds a Defender exclusion for DTF's folder automatically, and our Discord support walks you through it if your AV asks.
